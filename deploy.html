Deploy Resole

Deploys contracts/Resole.sol (Solidity 0.8.20, optimizer 200 runs, EVM paris) from your MetaMask account. Prices are in BOT only. The contract has no constructor arguments and can only be deployed on BOT Chain mainnet (chain ID 677): on any other network the deployment reverts.

Ready. Each button asks you to confirm one transaction in MetaMask.
  1. After deploying, open the app on this same localhost address. It picks up the new address automatically.
  2. For the live site, paste the address into contract: '' in CONFIG.networks.mainnet near the top of the script in index.html, set fromBlock to the block shown above, and update the README.
