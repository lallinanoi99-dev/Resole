Deploy Resole

Deploys contracts/Resole.sol (Solidity 0.8.20, optimizer 200 runs, EVM paris) from your MetaMask account. The only constructor argument is the USDT token address. Deploy to testnet first, try the app, then deploy to mainnet.

1 · Testnet (968)

Prefilled with the testnet USDT from the BOT Chain DEX token list. If you have none of it, deploy a mintable test token first and use that address.

2 · Mainnet (677)

Official Tether USD on BOT Chain (6 decimals), as listed on dex.botchain.ai and scan.botchain.ai. Leave empty to ship BOT-only.

Ready. Each button asks you to confirm one transaction in MetaMask.
  1. After deploying, open the app on this same localhost address (add ?net=testnet for testnet). It picks up the new address automatically.
  2. For the live site, paste the address into the matching contract: '' field in CONFIG.networks near the top of the script in index.html, set fromBlock to the block shown below, and update the README.
